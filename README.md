# homework-ai · สมุดลายมือ

เว็บแอปหน้าเดียวสำหรับเปิดใบงาน ตรวจและแก้คำตอบ AI คัดลายมือ และเขียนคำตอบลงบนภาพใบงาน ใช้ HTML5, CSS3 และ JavaScript โดยเปิดจาก `index.html` ได้เลย

## เริ่มใช้งาน

- เปิด `index.html` ใน Chrome, Safari, Firefox หรือ Edge รุ่นปัจจุบัน แอปเริ่มที่ใบงานคณิตศาสตร์ตัวอย่างพร้อมคำตอบ จึงลองแก้คำตอบ คัดลายมือ และส่งออกได้ทันที
- บนมือถือให้เปิดหน้าเว็บผ่านเบราว์เซอร์ หากแอปดูไฟล์แสดงเพียงภาพตัวอย่างของ HTML ให้เปิดผ่านลิงก์ GitHub Pages
- รูปภาพ การแก้คำตอบด้วยตัวเอง สตูดิโอลายมือ และการส่งออกทำงานได้โดยไม่ต้องใช้ API Key การเปิด PDF ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด PDF.js จาก jsDelivr ส่วนการสแกน AI ต้องเชื่อมต่อผู้ให้บริการที่เลือก

## เปิดบน GitHub Pages

1. ไฟล์ `index.html` อยู่ที่รากของรีโพซิทอรี `bosszest964-star/homework-ai`
2. เปิด **Settings → Pages** เลือก **Deploy from a branch** จากนั้นเลือกสาขา `main` และโฟลเดอร์ `/ (root)` แล้วบันทึก
3. เปิด URL ที่ GitHub แสดงในหน้า **Pages** การรันเว็บใช้เพียง `index.html` ส่วน README และชุดทดสอบใช้ประกอบการพัฒนา

## สแกนและตรวจคำตอบ

1. แตะ **ถ่ายรูป** เพื่อใช้กล้องหลังตามที่เบราว์เซอร์รองรับ หรือเลือกไฟล์ JPG, PNG หรือ PDF ผ่านช่องนำเข้าไฟล์ บนคอมพิวเตอร์ลากไฟล์มาวางได้
2. เปิด **ตั้งค่าสมอง AI** เลือก Gemini (`gemini-2.5-flash`) หรือ OpenAI (`gpt-4o-mini`) วาง API Key แล้วกด **บันทึกการตั้งค่า** แอปจำรหัสแยกตามผู้ให้บริการ ลบรหัสได้โดยเปิดหน้าตั้งค่าแล้วบันทึกช่องว่าง
3. กด **สแกนใบงานและเขียนคำตอบด้วยลายมือฉัน** ไฟล์หลายหน้าจะสแกนทีละหน้า คำตอบจะปรากฏบนกระดาษทันทีที่ประมวลผลหน้านั้นเสร็จ แต่ละข้อมีประเภทโจทย์ ข้อความคำตอบ วิธีคิด และกรอบพิกัดบนภาพ
4. แตะรายการใน **ตรวจและแก้คำตอบ AI** หรือแตะกรอบบนใบงานเพื่อแก้ข้อความ อ่านวิธีคิด เลือกวงกลมหรือกากบาท หรือปรับพิกัด กด **ให้ AI คิดใหม่ข้อนี้** เพื่อขอคำตอบเฉพาะข้อ แล้วกด **บันทึกคำตอบ** เพื่อใช้ผลใหม่
5. กด **เพิ่มกล่องคำตอบเอง** ได้ทุกเมื่อโดยไม่ต้องตั้ง API Key สำหรับโจทย์ปรนัยที่เพิ่มเอง ให้ย้ายกรอบไปครอบตัวเลือกที่จะทำเครื่องหมาย

เมื่อสแกนซ้ำ ผลที่ AI สร้างในแต่ละหน้าจะถูกแทนที่หลังจากสแกนหน้านั้นสำเร็จ ส่วนรายการที่เพิ่มเองยังอยู่ ตรวจคำตอบและตำแหน่งกรอบก่อนส่งออก โดยเฉพาะภาพเอียง ภาพไม่ชัด หรือโจทย์หลายคอลัมน์

## คัดลายมือและสำรองข้อมูล

1. เปิด **สตูดิโอลายมือ** เลือกหมวดตัวอักษร แล้วเลือกตัวที่ต้องการคัด
2. เลือก **แบบที่ 1**, **แบบที่ 2** หรือ **แบบที่ 3** แล้วเขียนด้วยนิ้ว ปากกาสไตลัส หรือเมาส์ตามโซนที่เน้น กระดานแบ่งพื้นที่เป็นวรรณยุกต์ สระบน พยัญชนะหลัก และสระล่าง ปรับหัวปากกาได้ และใช้ **ย้อนกลับ** เพื่อลบเส้นล่าสุด หรือ **ล้างช่อง** เพื่อลบทั้งแบบที่กำลังคัด
3. แอปบันทึกหลังจบแต่ละเส้นลง IndexedDB เมื่อกลับไปที่ใบงาน แอปจะใช้ตัวที่คัดไว้และสุ่มเลือกจากแบบที่มี หากยังขาดตัวใด แอปใช้ฟอนต์สำรองหรือลายเส้นสระและวรรณยุกต์ในตัว และคงรูปแบบที่สุ่มไว้ในตำแหน่งเดิมเมื่อปรับมุมมองหรือส่งออก
4. ใช้ **บันทึกไฟล์ลายมือเก็บไว้** เพื่อดาวน์โหลด JSON และ **อัปโหลดไฟล์ลายมือเดิม** เพื่อกู้คืนหรือย้ายไปอีกเครื่อง การกู้คืนจะแทนที่คลังปัจจุบันหลังยืนยัน

## จัดใบงานและส่งออก

- ใช้ปุ่มก่อนหน้าและถัดไปสำหรับ PDF หลายหน้า และปุ่มย่อหรือขยายเพื่อเปลี่ยนเฉพาะมุมมอง
- ลากกรอบคำตอบด้วยนิ้วหรือเมาส์เพื่อเลื่อนตำแหน่ง บนคีย์บอร์ดให้โฟกัสกรอบแล้วใช้ปุ่มลูกศร กด Shift ค้างไว้เพื่อเลื่อนครั้งละมากขึ้น
- เลือกหมึกน้ำเงิน ดำ แดง หรือดินสอ และปรับขนาดลายมือกับระยะบรรทัด การตั้งค่านี้ใช้กับใบงานทุกหน้า ข้อความจะย่อลงอัตโนมัติเมื่อพื้นที่ในกรอบไม่พอ ขยายกรอบในหน้าต่างแก้คำตอบได้หากต้องการลายมือที่ใหญ่ขึ้น
- กด **บันทึกใบงานส่งครู** แล้วเลือก PNG ความละเอียดสูงของหน้าที่เปิดอยู่ หรือ PDF ที่รวมทุกหน้า ไฟล์ส่งออกจะรวมลายมือไว้ในภาพ PDF ที่ส่งออกจึงเป็น PDF แบบภาพ

## การเก็บข้อมูล

รหัส API ใช้ `localStorage` ของไซต์หรือไฟล์ที่เปิด ลายมือใช้ IndexedDB ของเบราว์เซอร์เดียวกัน การเปิดจาก URL อื่นหรืออุปกรณ์อื่นอาจได้คลังคนละชุด และบางเบราว์เซอร์อาจจำกัดการเก็บข้อมูลเมื่อเปิดไฟล์โดยตรงหรือใช้โหมดส่วนตัว ใบงานที่กำลังแก้อยู่ในหน่วยความจำของแท็บ ให้ส่งออกก่อนรีเฟรชหรือปิดหน้า

แอปส่งรหัสและภาพใบงานไปยัง Gemini หรือ OpenAI เฉพาะเมื่อขอสแกนหรือให้คิดใหม่ ผู้ให้บริการอาจคิดค่าบริการตามบัญชีที่ใช้ รหัสที่เก็บในเบราว์เซอร์ไม่ได้เข้ารหัส ควรใช้รหัสของตนเองบนอุปกรณ์ที่ไว้ใจได้

## รันชุดทดสอบ

ใช้ Node.js 18 ขึ้นไป โดยไม่ต้องติดตั้งแพ็กเกจ

```sh
node tests/thai-layout.test.mjs
```

ชุดทดสอบอ่านโค้ดจัดวางจาก `index.html` โดยตรง ครอบคลุมสระหน้า สระบน สระล่าง วรรณยุกต์ สระอำ การหลบส่วนสูงของ ป ฟ ฝ ฬ การตัดคำตามความกว้าง การคงบรรทัด และข้อความภาษาไทยผสมตัวเลขและสัญลักษณ์
